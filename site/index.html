See which chat used your Claude limits

usagemax is a Claude Code plugin for the Code tab of Claude Desktop. It shows what each request and each chat cost you in the 5-hour window and the weekly limit.

Install Source on GitHub

A line under every answer

◑ Used: +5.2%/+0.43% 121K Tok: share of the 5-hour window, share of the week, tokens sent and written. Yellow from 3% of the window, red from 6%.

A panel for the whole account

  • 5-hour window with reset time and run-out forecast
  • Pace: window used against time passed
  • Limits: 5-hour and weekly
  • Trend for 7 days and an hour heatmap
  • This chat: total, heaviest request, last 10 requests
  • Models: Opus, Sonnet, Haiku and Fable share
  • Top chats for the hour, today, yesterday, the 5-hour window or the week
  • Other: Chat tab, phone and other computers

A band and toasts

The band above the prompt shows this chat's share of the current 5-hour window in an orange chip that opens the panel, both limits with a bar and the time to reset, and an estimate when either limit would run out before its reset. Click the band to open the panel. Toasts fire at 80% and 90% of the window, at 80% of the week, when the window runs out before the reset, and when one chat uses over 10% of the window in an hour.

Install

Needs Claude Desktop with the Code tab and a Claude subscription with the 5-hour and weekly limits. Tested with Claude Code 2.1.304 on Windows 11.

claude plugin marketplace add Aristosya/usagemax
claude plugin install usagemax@usagemax --scope user

Questions

Does it count the Chat tab?

No. Usage from the Chat tab, the phone app and other computers lands in the Other row.

How is a request's share computed?

usagemax prices tokens by Anthropic's list prices and learns one account-wide rate per window from the last 7 days. A request's share is its cost times that rate.

Does it send data anywhere?

No. Prompts (first 120 characters) and token counts stay in local files for 30 days.

Does it work with an API key?

API-key sessions have no 5-hour or weekly window. The line shows tokens only.
